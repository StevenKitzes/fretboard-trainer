Metronome (BPM)


The following tools will help you practice the exercises in the video!

Exercise levels:

  1. Practice, starting with the natural notes (A, B, C, D, E, F, G)! For each note, find that note on every string and play it. Take your time, it's just about getting familiar!
  2. Repeat exercise 1, but use the metronome, starting at 40 BPM! Try to play with the metronome, playing each note on every string before moving to the next note.
  3. Add sharp and flat notes! Once you can keep up with the metronome when practicing the natural notes, repeat steps 1 and 2 for sharps and flats of all the notes!
  4. Advance the practice difficulty: get two random notes, play one of them going up the strings, and the other one going down the strings! Use the button below to generate two random notes below, with their tabs in case you need them.
    Check the box to include accidentals (sharps and flats):
  5. Advance the practice difficulty further: practice all 7 natural notes in order, alternating up and down the strings without breaks; one note up all the strings, next note down, and so on; once that is easy, practice the same exercise in a random order, alternating up and down for each note! Use the button below to generate 7 random notes to practice with.
  6. As things get easier, gradually increase the metronome speed until you can play at 80 BPM!
